# Contributing

Contributions are offered under GPL-3.0-or-later, without copyright assignment. Retain existing
third-party notices and identify external code, its source revision, licence and modifications. Do
not submit code whose redistribution rights you cannot establish.

Please include a `Signed-off-by: Your Name <email>` trailer certifying the
[Developer Certificate of Origin 1.1](https://developercertificate.org/). See `AGENTS.md` for the
layout, the build and test commands and the working rules.
